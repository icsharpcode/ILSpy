## Behavior-preservation commitments

- No prompt text, YAML metadata semantics, or prompt ID changes.
- No settings XML element names/order changes; schema-2 and legacy migration behavior byte-for-byte per existing tests.
- No credential identity generation changes (`SecureKeyStorage` account naming, file locations, P/Invokes).
- No public provider request contract changes (`LLMRequest` fields, streaming interfaces, SSE parsing, endpoint validation, loopback-only plain-HTTP rule).
- Context budgets (`DefaultMaxContextTokens` etc.), privacy consent gating, rename annotation behavior, security confidence threshold (`0.70` double), audit cap (`MaximumTypesPerAudit = 50`), and chat command routing unchanged.
