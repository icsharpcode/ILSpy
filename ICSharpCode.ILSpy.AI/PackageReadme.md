## About

ICSharpCode.ILSpy.AI is the portable AI/LLM infrastructure used by [ILSpy](https://github.com/icsharpcode/ILSpy/): provider transports (OpenAI-compatible and Anthropic), profile and selection state, prompt loading with embedded fallbacks, secure credential storage, and chat/token utilities. It has no dependency on the decompiler or any desktop UI framework.

Decompiler-aware AI features (explanation, rename suggestions, semantic search, security analysis) live in the companion package `ICSharpCode.ILSpy.AI.Decompiler`.
